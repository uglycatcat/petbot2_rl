# PetBot Step RL Demo

**状态：** 已登记的任务线占位仓库；当前仅记录目标，尚无训练代码、实验或策略。

## 任务目标

机器人从正常四轮接地状态开始。策略先让前轮抬离地面，再将前轮放到高度为 **0–3 cm** 的低台阶上；台阶高度低于后轮半径。前轮落上台阶后，机器人通过加速带动后轮“爬”上台阶。

本任务用于学习低台阶攀爬，不包含跌倒恢复。阶段奖励、台阶几何、初态与速度分布、成功判据和控制接口尚待设计与仿真验证；不能把这份任务描述当作已有实现或训练结果。

## 实施顺序

当前项目主线先继续强化 upright_rl_demo。待起立效果达到下一阶段标准后，再在本仓库定义并实现台阶任务。
