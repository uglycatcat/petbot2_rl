# upright_rl_demo

PetBot2从默认构型、零速度开始，前轮离地、仅后轮支撑稳定，最终回到初始水平位置。过程允许位移，头和耳保持初始位置目标。两路策略分别为左右车架共享位置目标、左右后轮共享速度目标，不输出力矩，不使用示范数据。

## 第二版（2026-10-16）

单策略两阶段：实际前轮净空与后轮接触确认后，从抬升转入平衡回位。三帧接触多数确认，连续0.1秒进入；丢失支撑0.06秒退回。首次阶段奖励每回合仅一次。

成功要求连续1秒有效后轮支撑、前轮中心>0.12m、无其他部位支撑，水平位置误差≤0.05m、头耳实际偏差≤0.05rad、线速度<0.10m/s，窗口内重力方向和水平朝向波动范数各<0.05、位置关节角摆幅<0.03rad。这是位姿窗口判据，不要求每个物理步的关节速度都小于固定低阈值。默认站住、远处平衡、掠过起点均不算完整成功。位移>0.6m、跌倒、非有限状态或异常速度终止。

奖励：抬升阶段持续准备/离地奖励上限2/s（抬头贡献至多0.5/s），阶段2有效后轮支撑2/s；另包含上限0.25的抬头准备势、实际离地势和回位势；准备势不触发离地事件或成功。折扣势差3、首次离地事件3、后轮支撑下速度/回位联合评分2/s、首次完整成功30、完整保持5/s；超出0.4m的距离平方−2/s、动作差平方−0.002/s、跌倒−5。势差使用gamma=0.997，失败终态势为零；没有固定姿态轨迹或阶段动作表。速度评分参考指向起点，模长≤0.2m/s，不全程奖励轮速为零。

150维观测为5帧×30维：重力、水平朝向、根速度、5关节角度/速度、后轮速度、相对起点误差、上一动作、阶段、保持计时及回合时间。12秒回合、50Hz控制。有界原生Beta动作，初始std 0.25/0.15，固定lr=0.0006、gamma=0.997、32步rollout、5epochs、4minibatches、entropy=0.001；不采用recovery的终态方差门控。源MJCF及派生资产的物理参数不变。

详细设计和MuJoCo行为复现见主仓库 `docs/upright_v2_design.md`。`jump_demo` 仅作行为与判据参照。

## 容器和固定版本运行

独立Isaac Lab3.0.0-beta2 / RSL-RL5.4.1容器 `petbot-upright-train`，仅GPU0/1。`bash tools/container.sh up`，依赖安装用`install`。训练只在容器内，正式运行应从干净固定提交的独立副本启动，源模型只读。

`train.py --num_envs 2048 --iterations 3000 --seed 42 --log_dir <目录>`；`--evaluate --checkpoint <文件>`确定性重载，默认延长2秒检查保持。`--probe`固定默认目标负控制。评估输出离地/平衡/完整成功/终局/额外保持、位移、实际头耳偏差和完整前4环境轨迹，不将重复默认初态当场景覆盖率。`checks/progress_contract.py`需要CUDA，只验证判据、复位与奖励排序，不能代替PhysX验收。

宿主`tools/run_guarded.py`逐秒检查对应GPU总显存，78%停止自己的专用容器，给80%限制留余量；记录采样峰值与退出码，不声称捕获采样间瞬态。GPU0发起前需按实测足迹保留预算。`tools/evaluate_v2.py --root <主仓库>`一次性串行评估250/750/1500/2999，不自动重训，有锁防重。
