# PetBot upright：从零重建

本项目正在按用户要求重新建立训练工程。**当前没有可用的新版训练实现，不启动训练或自动迭代。** 旧实现已完整封存，不能将旧继承式网络、奖励、课程或后来的scratch入口当作重建基础。

交付目标是在没有历史检查点、父网络和示范数据的环境中，从随机初始化学会：四轮运动中接管 → 直线起立 → 两轮持续遥控 → 前轮落地 → 普通控制；意外倒下立即退出。双向连续0–0.75m/s、不同共同髋初态、左右镜像行为与稳定性要求保持。
