## 桌面复现与相机兼容修复（2026-10-27）

RTX 2080 Ti 桌面机按 `uv.lock` 安装 Python 3.10.20 / MuJoCo 3.16.0 / PyTorch 2.10.0+cpu。默认 r42 以键盘上限混合指令完成起立、18秒两轮遥控、落地与交接：25.08秒仿真耗时15.19秒，failure=0，完整/基本均通过，6/6响应及停车检查通过，最大停车位移3.59mm；EGL实际渲染正常。证据保存在项目 `outputs/local_20261027_1559_mixed/`，属于单条复现。

真实X11窗口可打开，但鼠标拖动暴露首版遗漏：MuJoCo 3.16的 `mjv_moveCamera` 接收5个参数，旧拖动/滚轮调用多传了 `scene`，触发 `TypeError`。两处调用已去掉该参数。用真实OpenGL窗口执行已注册的拖动、放大和缩小回调，逐项断言相机参数发生变化，运行2秒并正常销毁窗口，检查通过；旧窗口启动验收不能替代鼠标回调验收。此次未改策略、控制链、锁文件或源模型，原有落地和重复起立失败仍保留。

## 成熟度判断

已有可复现的训练、导出和包含全部反馈环的跨引擎控制器，默认低速场景能够完成长时两轮遥控与起落闭环。仍需处理跨引擎落地交接、重复接管及初态/航向覆盖，之后再决定正式训练项目迁移。当前定位为可体验、可诊断的原型，不能认定仅调整超参数即可成熟。
