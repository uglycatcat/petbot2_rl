# 四个固定倒地姿态的零后轮目标恢复动作

四个指定初态均已找到可复现的开环动作。两后轮速度目标始终为0，五个位置关节改变构型，成功后保持末目标至16 s。它们来自从零整回合随机动作/CEM搜索，没有使用demo动作、旧权重或教师；没有添加默认关节角收尾。动作不是具有扰动适应能力的反馈神经网络。

[观看四姿态恢复视频](recovery_four.mp4)。视频为原始MJCF、0.5 ms积分步长的实际重放，四个画面使用各自的动作。模型和四份用户快照未修改。

| pose_01 | 14.90 / 14.88 / 14.90 s | 1.62 s | 14/16 | [视频](pose_01/recovery.mp4) |

成功须四轮持续承重、机身朝上、非轮部位离地并停稳0.5 s，具体阈值见项目设计。所有原模型重放无越界，末态仍稳定。PhysX数字是完全相同初态的场地副本，不是扰动成功率；没有实机验收。

pose_01的两个PhysX副本已经翻正，但左后轮间歇失去有效承重：14.52—16 s分别有9/6个控制步未满足接触条件，最长连续稳定只有0.36/0.42 s，仍按失败统计。其他稳定条件在该区间均满足。[实际PhysX轨迹视频](physx_cases.mp4)展示成功env0、未达标env4及pose_02/04；用原网格显示记录的运动，没有重新运行MuJoCo动力学。完整数字见`physx.json`、`physx_case_review.json`、`physx_failure_causes.json`。

## 与已知恢复方法的区别

四条动作都没有已知demo的后轮正反速度脉冲。到首次成功，轮电机净功估计分别约−0.125 / −0.0149 / −0.0722 / −0.0689 J，表现为制动。**零速度目标仍会产生制动力矩，不等于关闭轮电机或取消地面摩擦。** pose_01/03/04仍有双后轮支撑阶段，因此不能仅据零目标称为完全不同的支撑路线。

pose_02提供了更明确的另一条支撑路径：先有头部、右耳和前轮接地，随后以前轮及左后轮支撑；到机身首次达到朝上判据的6.14 s，右后轮地面接触力始终为0，没有双后轮同时支撑。原模型三种积分步长的每个物理子步均核对一致。它在6.84—6.86 s满足完整稳定判据，说明在当前模型与该固定初态中，恢复不必先建立双后轮支撑并爆发驱动。证据为`pose02_support_resolution.json`、`pose_02/mechanism.json`及对应视频。这不是对全部姿态或真实地面的保证。

支撑分析采用仅地面接触的力，排除自接触；电机功为物理子步力矩乘步末角速度的数值估计，不作精确能量或因果分解。所有动作仍使用原模型的接触、摩擦、关节限位与力矩限制。

## 复现

在项目根目录、已安装项目依赖的环境中执行。服务器必须使用本项目专用容器；桌面机可做MuJoCo验证。

```bash
python replay_witness.py \
  --witness release/four_pose_zero_drive_20261118/pose_02/action \
  --output outputs/four_pose_zero_drive/pose_02 \
  --physics-dt .0005 --hold-final-seconds 9.14 --video
```

| 动作目录 | 已记录步数 | 保持末目标至16 s的`--hold-final-seconds` |
|---|---:|---:|
| pose_01 | 744 | 1.12 |
| pose_02 | 343 | 9.14 |
| pose_03 | 138 | 13.24 |
| pose_04 | 263 | 10.74 |

`action.npz`包含每20 ms的七维归一化绝对目标、完整初始根状态和关节状态。前五维为头、左耳、右耳、左轮架、右轮架，按项目范围映射；后两维为左右后轮速度目标除以25。前轮被动，位置关节采用源限幅PD。重放器核对动作SHA、源模型和指定初态，不能从任意姿态直接播放。

原完整800步随机动作可能在成功后又使机器人倒下；本包保留到搜索及独立原模型成功时刻中的较晚者，之后保持末目标，三种步长与PhysX验证均针对该派生版本。pose_01原PhysX选优记录仅稳定0.34 s，但独立原模型与本包PhysX复验确认恢复。原始搜索记录、派生关系和完整轨迹在对应运行目录保留。

PhysX独立重放命令（具备Isaac运行环境的专用容器）：

```bash
python tools/replay_targets_physx.py \
  --sequences release/four_pose_zero_drive_20261118/physx_sequences \
  --output outputs/four_pose_zero_drive/physx --num-envs 64 --headless
```

每姿态目录含三份原模型报告、动作、视频、关节目标/实测图与支撑分析。`manifest.json`记录搜索来源；pose_01/02/04来自冻结`0af50800`正式搜索，pose_03来自seed886从零容量检查，保留其实际源码指纹，不冒称由正式批次产生。`SHA256SUMS`用于校验包内文件。
