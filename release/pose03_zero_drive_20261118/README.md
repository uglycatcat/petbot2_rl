# pose_03：零后轮速度目标的恢复动作

这是从指定pose_03起点搜索得到的开环动作策略。两后轮目标全程为0，位置关节改变构型；原模型中7.06 s达到四轮支撑、机身翻正及静止判据，保持末目标至16 s仍稳定。它仍利用后轮支撑与制动，不能理解为不用后轮或不依赖地面摩擦。

来源：从零CEM搜索，seed901，第3代；固定源码`6237de6e84e4351b18f9a9b397dac61c63c6959d`。没有demo动作、历史权重或教师初始化。原800步序列成功后又被后续随机目标带倒，因此本包截取首次成功前353个实际目标，之后保持末目标。原始序列在运行目录保留。

| 验证 | 结果 |
|---|---|
| 原MJCF，2 ms、implicitfast | 7.02 s成功，连续稳定9.48 s，16 s时仍稳定 |
| 原MJCF，0.5 ms、implicitfast | 7.06 s成功，连续稳定9.44 s，16 s时仍稳定 |
| 原MJCF，0.25 ms、implicitfast | 7.06 s成功，连续稳定9.44 s，16 s时仍稳定 |
| PhysX，16个固定初态场地副本 | 6个成功；存在引擎/副本敏感性，不是宽初态成功率 |

[恢复视频](recovery.mp4)展示0.5 ms原模型重放，黄色标记表示首次成功后保持末目标。[关节目标与实测](pose03_plots_pose_03_joints.png)和[姿态/接触图](pose03_plots_overview.png)用于核对动作。源模型、四份原始快照均未修改；未做实机或初态扰动验收。

在项目根目录、具备MuJoCo和项目Python依赖的环境中运行（服务器上必须在专用容器内）：

```bash
python replay_witness.py \
  --witness release/pose03_zero_drive_20261118/action \
  --output outputs/pose03_zero_drive/replay \
  --physics-dt .0005 --hold-final-seconds 8.94 --video
```

`action.npz`保存353×7个20 ms归一化绝对目标，以及完整初始根/关节状态。前五维顺序为头、左耳、右耳、左轮架、右轮架，映射关节范围；后两维为左右后轮目标/25。位置关节使用项目源限幅PD，前轮被动。程序自动核对源模型和pose_03，不能直接从其他姿态播放。

与已知demo相比，本动作没有后轮正反速度脉冲。到首次成功前，按物理子步估算轮电机净功约−0.0922 J，体现制动；已知demo通过同一控制接口约+0.1953 J。本动作也存在双后轮支撑，左耳和左轮架曾接地；支撑机制与已知方法有重叠，不能仅因目标为0就宣称全新的支撑路线。数值细节见`drive_comparison.json`和`pose03_mechanism.json`。
