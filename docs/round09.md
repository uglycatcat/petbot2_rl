# Step第9轮：修复后轮跨沿离地判据

第8轮seed71的64个旧后轮失败窗口到实际台阶表面均≤1.773mm，低于原4mm容差。原代码直到整个后轮越沿才改用顶面高度，此前只参考下方平地，遗漏棱边/立面支撑。2ms原动作回放347280项物理标量完全一致；原0/64不能作任务能力结论。前几轮近沿“真实后轮离地”解释撤回，旧力/运动/触发记录保留，不能未经逐例复核声称全部历史失败都误报。

本轮只修复这项几何计算并增加诊断记录。保持第8轮奖励、Beta方差课程、26维自身传感actor、两共同动作、PD及变化率、机器人/地形物理和全部完成要求。新训练继续随机初始化，不使用历史权重或示范数据。

每2ms将原轮廓顶点变换到世界坐标，使用凸包边在XZ投影上计算到有限平台矩形及地面的距离，覆盖前后立面、棱边和顶面；凸包三角化边包含任意朝向下的轮廓边。地面延伸到平台之后，几何保持原0.1mm包络。轮子完全处于平台宽度内时投影距离准确；横向超出时加入横向区间间隙，得到不会夸大真实离地距离的保守下界。侧向退出仍由原COM±0.15m边界独立拒绝；不会据此授予顶面支持或成功。

后轮失败继续要求间隙>4mm、合力<0.02N并持续>20ms。新增`rear_clearance`只用于终止与记录，不进入actor，也不改变前轮碰撞、四轮支持、归髋、直行或停稳判据。真正离地与暂时无接触力但仍贴近地形的情况必须区分。

候选72项容器检查通过，包含平地/顶面等价、跨沿、角点最近边、无顶点进入矩形时的边交叉、有限平台远端、横向边界、世界平移以及原力/间隙阈值。640个原触发窗口子步的独立轮廓距离对照误差≤3.57e-7m。仍须完成容器PhysX滚边续接与真实腾空反例、短训/恢复/重载和512环境规模检查，不能仅凭这些CPU检查发正式批次。

工程续接只使用本轮原始动作前缀，到各环境原终止点后使用有限预设动作，不串用重置回合动作；不做策略优化，不输入PPO。已被旧判据提前截断的轨迹不直接改计为成功。正式预算保持种子70/71各512环境×500更新、各64回合独立评估，仅物理GPU0/1，沿用原完成/异常事件链。工程证据完成后补录，固定副本不得修改。
