# 跳跃预研（2026-10-15）

与服务器上的 PetBot 第三轮摔倒恢复训练无关，也不改那一批代码或运行副本。第三轮状态见[第三轮记录](petbot_sweep3_training.md)。本页只记录本机 MuJoCo 上「前轮能否离地」的预研，以及据此另开的跳跃 demo 线。

## 已测到的

两处都在桌面机、`mujoco_env`、只读 `robot_description/mjcf/scene.xml`，积分器用 MuJoCo `implicitfast`。源模型未改。

数学测试 `robot_controller_demo/test/rear_wheel_inverted_pendulum/test_lift_feasibility.py` 不做时间积分、不开窗口。四轮着地静止姿态上解一次约束动力学：左右后轮同为 +25 rad/s，左右车架同为 −1.20 N·m。扣除静摩擦后，前轮垂向加速度 +55.79 m/s²，后轮支持力 44.71 N，所需摩擦 0.507，模型后轮摩擦 1.500。仅轮速为 +3.90 m/s²，仅车架为 +33.73 m/s²；车架力矩反号则前轮加速度为负。车架角为 0 时，抬头 0.925 rad 的姿态质心落在后轮轴上方，前轮离地 0.137 m，且越过该角后重力矩继续推离。这证明限位内的对称指令能让前轮离地且后轮保持受压、不打滑，倒立摆平衡落在关节限位内。它没有积分出一条摆到该平衡点的轨迹。

`robot_controller_demo/jump_demo/` 是带窗口的时间积分。无头测试通过的界限是：前 2 s 前进超过 0.30 m；车架角先超过 +0.9 rad，再收到 −0.35 rad 以下；前轮中心高于 0.12 m 且后轮中心低于 0.042 m 的连续时间超过 4 s；12 s 末尾 1.5 s 内水平速度绝对值低于 0.08 m/s、位置波动低于 0.06 m，前轮仍离地、后轮仍着地。用户于 2026-10-15 看过窗口，确认这就是要的实现。同时打开的数据窗口只显示车架位置、后轮速度和 IMU 的 roll / pitch / yaw，不改变动作。
