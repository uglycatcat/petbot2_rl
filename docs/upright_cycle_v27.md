## 修改

从零入口默认`configs/scratch_v2.json`，策略仍是全部可训练的20ms MLP，物理模型和动作/普通控制、阶段成功判据均不改。只有起立阶段的过渡/平稳正奖励按真实前轮抬升比例加权，避免四轮驻留持续得分；落地与两轮奖励保持。准备俯仰只给有限的历史新高进展分，起始已有俯仰不计贡献，重复摆动/停留不再重复得分；真正前轮抬升继续给进展分，进入两轮恢复5分事件奖励，稳定3秒和完整交接条件不降。

准备俯仰是物理机制的奖励引导，不是指定关节动作、教师策略或动作轨迹；每次调用准备贡献最多1分。新增真实轮隙、离地调用和两轮入口统计，便于分辨学会准备、开始离地、进入两轮和完整成功。
