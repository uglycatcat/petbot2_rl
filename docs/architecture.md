# Step训练实现

`isaac_env.py`为向量化DirectRLEnv，`ppo.py`使用RSL-RL 5.4.1原生OnPolicyRunner/PPO；`runtime.py`负责随机初始化来源、同次恢复、独立重载和失败状态。没有跨demo导入或权重依赖，不包含sim2sim。

## 数据通路

每回合一次的2cm/30cm/90°包锁存后，actor只接收26维自身观测：原始包4维，估计剩余法向距离与相对角3维，估计横向位置/航向/速度5维，重力方向和陀螺6维，髋角/髋速度/后轮速度6维，上一执行动作2维。critic使用相同信息、独立归一化。没有真实位姿、真速度、接触标志或阶段编号进入网络。

IMU按2ms采样，陀螺积分姿态，加速度去重力后积分。编码器正运动学修正传感器到整机质心偏置；后轮角速度、共同髋速度和陀螺估算后轮滚动速度，以0.1s时间常数融合平移速度。低轮速/低角速且加速度近重力时做静止修正和倾角校正。此通路使用后轮支撑假设，打滑和传感漂移仍须通过真值离线对照，不把编码器里程计称为真实位移。

动作共同髋角映射[-1,1.2]rad，共同后轮目标[0,25]rad/s；左右输出严格相同，目标分别限速3rad/s、100rad/s²。头耳目标为0、前轮被动。共同控制不保证实测运动完全对称，评估保留两侧真实关节及原直线误差。

## 模型与PhysX

`tools/prepare_asset.py`从只读MJCF/STL生成step自己的USD。MuJoCo库仅编译源模型并做正运动学/质量解析，不推进动力学、不做策略验证。转换前后检查源指纹，默认整机质量1.65254kg，平台前沿相对初始质量加权COM加0.30m。

派生资产修复导入遗漏：轮与自身其它刚体碰撞过滤、独立接触报告、同名几何节点重命名（避免PhysX传感器多匹配）、静摩擦与混合规则。源文件不变。前轮接触摩擦0.1采用min，后轮1.4采用max，地面/平台1.5采用min，保持源前轮优先的接触意图。关节静/动摩擦、粘性阻尼、armature按源值显式映射；跨物理引擎的接触/摩擦求解不承诺完全等价。

髋/头/耳为显式位置PD，力矩限1.2/0.72/0.1Nm；后轮使用PhysX隐式速度驱动，kv=0.14、力矩限0.38Nm，前轮无主动驱动。后轮显式速度PD在2ms下出现数值轮速震荡，改用隐式求解保留增益和力矩参数。`controller_effort_estimate`为控制器估计，不能当真实力矩传感测量。轮目标限25与实际轮速峰值分开统计。

## 奖励与完成

每个2ms子步记录轮网格几何、平台过滤接触力/接触点和支撑，不只看20ms末帧。几何用于判据的网格顶点按0.1mm量化后取凸包，边界外扩0.1mm以保守判断净空；不更改物理碰撞网格。

前轮须在边沿前有净空、整体越沿后才落顶面；平台水平法向力或边沿接触触发失败，失败标志当回合锁存。后轮离面超过4mm且无接触持续20ms判离地；机体接触/明显倾倒、偏离线过大和超时终止。顶面支持允许20ms接触间歇，但仍须几何贴近顶面。四轮上台、髋归零、原线/航向对齐后净前进0.15m，再持续0.5s停稳才成功；条件丢失清除直行/停稳信用。

奖励采用净前向进展、抬轮新高度、首次前轮落顶面、首次全部登台和最终停稳。平台里程碑只奖一次；另罚时间、动作变化、偏航/横移、髋未归位和落顶面的冲击。静止地面没有持续正奖励。数值均为首版工程初值，尚不能证明训练收敛。

## 训练与证据

当前默认第2轮512环境、每环境64步rollout、PPO 5 epoch/4 minibatch、2×128 ELU actor/critic、固定学习率3e-4、clip0.2、gamma0.99、lambda0.95、原生有界Beta分布；默认1000更新。首版Gaussian配置仅作历史复现，不能作为后续默认。工程配置128环境6更新，不能混作正式训练。

新运行创建唯一身份、代码/源模型/派生资产指纹、完整配置、随机初始化参数及空优化器证据。检查点保存actor/critic/归一化/优化器、实际学习率、更新计数和Python/NumPy/Torch/CUDA随机状态。恢复只接受原运行原配置，重新建立物理回合；RSL-RL保存的是0基更新索引，恢复从iter+1继续，不重复最后一次更新。

宿主机`freeze.py`从干净提交创建固定副本；`run_guard.py`只编排专用容器，检查GPU整卡显存、日志与实际状态文件。异常只终止本次专属进程组，不干预其它用户工作。最新用户已授权完成事件驱动的正式训练迭代，只使用GPU0/1；流程见`automation.md`，无goal或周期定时器。

评估按每个环境第一个完整回合记分，保存终止前轨迹，避免自动reset掩盖失败帧。固定首版同初态并行评估不等于泛化测试。工程进展和已知缺口见[验收记录](engineering.md)。
