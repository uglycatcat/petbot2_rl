# STEP v2 当前实现

适用代码：当前v2扩容候选；工程证据见`scaling_validation.json`，最近完整训练仍为旧v2第1批。本文描述当前实现选择，不把网络、奖励或工程阈值固化成用户需求。任务目标见[STEP需求](../../../docs/step_scope.md)，授权和能力结果见[当前交接](../../../docs/step_current.md)。

## 任务与物理判定

`task.py`维护唯一状态：接近、前轮飞行、前轮落顶/后轮登台、四轮归髋对线、短行、STOP、完成；真实失败可从任意阶段终止。没有阶段控制接管。

实际平台接触点与竖直力认证落顶；接触报告缺口最多20ms且须仍贴近地形。前轮离地逐2ms检查，台下相对地面、落顶后相对台面；无接触且间隙超过4mm计次，真实有载落地结束飞行，第二次飞行或返台下不合格。后轮按地形间隙检查离地，四轮登台要求完整轮廓位于平台范围。

四轮支持、归髋与原线资格满足后，以净位移记录短行15cm；不合格时前进不计，后退仍扣减。达到距离后进入STOP，资格丢失、退回不足距离或速度超限均清空保持时间。每个2ms子步连续满足条件2.5s才成功；真实失败优先，截止时未完成判失败。数值契约在`configs/step_v1.json`，独立标量验收器自行从原始物理字段重算，不依赖训练标签判成功。

## 观测、网络与动作

RSL-RL PPO，GRU actor输入27维自身信息：一次性地形包、IMU/编码器、传感运动估计、上次执行目标和本地计时。无真实位姿、接触、阶段或仿真速度输入actor；回合结束清零循环记忆。critic为134维完整物理/任务状态，采用固定单位缩放。原生循环storage/mask保存与优化轨迹，不做在线归一化漂移。

两维动作映射为共同髋目标[-1,1.2]rad、共同后轮目标[0,25]rad/s。Beta原始髋支持[-1,1]、轮支持[-1.1,1]，物理裁剪使零轮速可采样；PPO保存原始样本及对应密度，不能把裁剪后动作冒充原始样本。随机小输出头初始均值[0,-0.64]、标准差[0.03,0.15]，所有参数可学习。当前正式配置每路4096环境×1000更新，每环境采样32控制步、8个小批次，每次更新131072条控制转移。两组各用seed70/71：A初始髋标准差0.03，B为0.10，其余算法与任务相同。32步是PPO存储边界，不重置回合、停稳计时或GRU；非终止边界由critic估计后续回报，真终止不bootstrap。缩短BPTT的学习影响仍须正式结果检验。

## 当前回报

有限15s任务、gamma=1。每步奖励为潜势差减有界质量成本；终端潜势归零。成功终端+40；失败/超时为-10加至多6分已合法取得的最佳进展，失败帧不得刷新最佳值。质量成本最多5，完整回报成功[35,40]、失败[-15,-4]。该排序不证明可学习性或排除失败之间的局部最优。

当前潜势范围：接近0–2；近沿抬高至多0.5、有效水平越沿至多1.5，两者受后轮支撑系数约束。越沿取双前轮较差侧，须第一次飞行且净空足够；飞行潜势最多4，真实合格落顶至少5，后轮登台5–6、归髋6–7、净行7–8、STOP8–12。几何奖励不能替代真实接触认证，停车信用还须满足完整短行与姿态资格。

质量成本包括实际髋运动、lower_body世界pitch及变化率、实测轮速超调；没有按阶段替换策略动作。当前候选效果尚未完成训练验证。

## 记录与验证

`review.py`从连续2ms原始物理流重算任务、运动峰值和阶段计数，包含终止子步、排除其后的重置回合，记录峰值位置。独立评估保留20ms控制轨迹和2ms物理流；训练控制日志每10步记录一次，终端记录保留所有环境。稀疏训练日志不能代替子步接触与停稳验证。

几何距离采用torch.compile融合原公式，不减网格或变阈值；保留TorchScript后端作对照。reset批量读取终端信息，复用默认传感器几何。guard设置`PYTORCH_ALLOC_CONF=expandable_segments:True`，支持GPU0–3并检查control白名单；记录整卡显存/计算利用率与专用容器进程显存，保留至少2GiB空闲。整卡利用率含其他用户，不能冒充STEP独占指标。

已完成的工程摘要见`refactor_validation.json`和`v2_reward_validation.json`，仅在核查相关代码时读取。有限电机正例、CPU/物理检查、短训恢复与重载证明工程链路，不是已学会策略；其权重、状态和轨迹不得迁移。未来按改动范围做必要验证，不固定重复历史整套流程。
