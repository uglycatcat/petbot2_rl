# STEP v2 实现与验收

2026-11-04重构。正式训练与自动迭代停止；当前工作是完成实现和工程验证。旧方案审查见主仓库`docs/step_restart21_20261104.md`，旧实现固定b5fe58b。

## 唯一任务状态

接近 → 前轮飞行 → 前轮落顶/后轮登台 → 四轮归髋对线 → 短行 → STOP → 完成。真实失败可从任一阶段结束。没有独立的单调intent与可倒退phase，也没有多套历史奖励开关。

接触资格由实际平台接触点及竖直力认证；不再用轮底低于台面2mm的几何硬界否认有载支持。短暂接触报告缺口最多20ms且必须仍贴近地形，不能凭空认证支撑。四轮登台仍要求完整轮廓位于平台范围。

前轮首次离地相对台下地面判断，落顶后再离地相对顶面判断，避免靠近立面使真正离地被漏计。无接触力且离面超过4mm的样本在2ms物理步内计次，任何真实有载落地立即结束本次飞行；短二次飞行不能被去抖合并。后轮以有限地形几何间隙检查真实离地。

归髋、对线、四轮支持后记录短行起点，以真实净位移判定15cm。任何后退都减少净距离；资格丢失时的前进不计入短行，并把起点前移。因此不能靠资格切换和往返刷距离。达到15cm后STOP阶段保持；失去支持/归髋/对线、退回不足15cm或速度超限会清空保持计时，不能完成。完成要求每个2ms子步满足原门槛共2.5s。真实失败优先；恰好截止时完成允许成功，其余截止回合失败。张量任务与独立标量检查使用相同公开契约，各自实现。

## 策略、critic与动作

RSL-RL原生GRU actor输入27维：原26维自身传感/运动估计/上次执行目标，外加本地计时。一次性地形包不更新；没有真实位置、接触、任务阶段或仿真速度进入actor。GRU记忆逐回合清零，PPO按原生循环轨迹/mask存储和优化；评估同样重置。

critic读取完整物理状态和所有持久任务变量（当前134维），包括飞行事件、支撑记忆、直行累计、保持计时、潜势和质量代价。两网络采用明确固定单位缩放，没有收集动作与PPO重算之间变化的在线归一化统计。

动作保持原共同髋[-1,1.2]rad、共同轮目标[0,25]rad/s，执行器参数、变化率和源模型不变。原始Beta髋支持[-1,1]、轮支持[-1.1,1]，固定物理裁剪使零速有非零采样区间。PPO记录原始动作和对应仿射密度；没有按任务阶段替换策略输出。所有参数从随机初始化学习。Beta以可学习的均值和集中度参数化；小随机输出头初始均值[0,-0.64]、标准差[0.03,0.15]，减少初始髋噪声导致的大量瞬间失败。初始轮均值约4.5rad/s；这只是初始化，不限制后续可学习动作范围。PPO为128步、8个小批次，工程512环境8更新。

## 回报

使用gamma=1的有限15s任务。每步奖励为任务潜势差减有界质量代价；终端潜势归零，完整回合内潜势严格抵消，不让失败的局部进度兑现为正回报。真实完成终端+40；失败/超时终端为-10加至多6分已合法取得的最佳进展。失败帧不能刷新最佳值；STOP低速及保持信用还必须满足归髋、对线、四轮支持和净15cm资格。全回合质量成本最多5，故成功完整回报在[35,40]、失败在[-15,-4]。失败仍为负，但合法接近和登台应比原地不动更有学习信号。

潜势覆盖接近、临沿抬升、后轮登台、归髋、短行和停止/保持，仅保留一个有界合法最佳潜势值用于失败终端信用。质量成本包含实际髋运动、lower_body世界pitch及pitch变化率、实测轮速超调；没有每秒存活奖励或时间罚分。此回报排序只证明完整成功优于失败，不保证随机探索必然发现成功，也不声称失败之间不存在早退倾向。是否可学仍需后续正式随机训练证明。
