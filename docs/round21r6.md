# 21r6：LAND近地共同髋回默认，减少接地确认期运动

21r5两份1000更新及八评估有效。低速基本由29/20提升31/26；高范围完整30/29、基本30/16，双向0.75未达。静止接触后后退0.132/0.096cm、总移动1.116/0.848cm；保留基础回归采样，但不能称全面改善。

真实轨迹发现LAND触地后约0.18秒确认期仍输出往复髋目标。102静止例髋目标0.31→0.49→−0.12rad，而轮目标已趋零，接地速度约+0.21m/s。正常交接后普通控制执行零输入；剩余主要运动集中在LAND末端。

只新增`landing_hip_default_projection=true`：在原LAND传感间隙0.04→0.012m投影内，共同髋目标按相同比例收至既有默认0rad；保留6rad/s目标变化率、源电机力矩、轮目标处理与0.18秒接地确认/普通交接时机。高处LAND、起立、两轮、普通及异常退出行为保持；无新观测、奖励或网络结构。默认false兼容旧配置。

固定21r5网络的隔离MuJoCo五场景均完成，仅作开发干预。静止/前进后松键/后退后松键的后轮轴总移动1.067/1.255/1.313→0.726/0.812/0.826cm；机体后退分别0.242/0.316/0.309→0.285/0.316/0.501cm，减小总运动但个别反向分量更差，停车尚未解决。持W/S最终普通控制仍同向约±0.14m/s。不能把这些结果当新PPO成绩或sim2sim通过。

141项容器检查后，需2048短训、128环境4→8同次恢复、两重载及固定网络静止/60秒低高范围PhysX检查。工程通过才发布两种子102/103各2048×1000新随机初始化；不加载历史/工程权重，仅GPU2/3。固定推理探针不产生训练数据，桌面仍第20轮。
