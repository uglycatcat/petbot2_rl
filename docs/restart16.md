# Restart16：停车诊断的程序修正

2026-11-03。完整目标仍是单次干净抬轮、四轮登台后归髋沿原线短行再停稳。当前只修正独立平台停车诊断；无辅助权重迁移、无旧权重初始化、不修改源物理或MuJoCo预览。第14轮动作范围、26维自身传感观测、Beta/RSL-RL PPO均保留。

## 实测依据及解释边界

Restart15中期抽查两路74680/66080控制帧，已有59.3%/69.8%帧发生过前轮离地，永久失去辅助成功资格；首次离地中位时间0.22/0.26s。原代码却继续采样至物理失败或15s超时，STOP覆盖计数也没有剔除这类失效回合。近期有效帧仍有轮速和髋角误差：抽查最近8192帧轮请求中位1.43/3.10rad/s、真实COM速度0.051/0.090m/s、最大髋误差中位0.073/0.310rad。忽略离地资格后的最长功能保持也只有0.10/0.02s。因此无效采样并非唯一原因，不能只改成功掩码就声称学会停车。

同次126更新检查点在1024条记录状态上CPU推理，轮请求均值中位2.28/3.10rad/s、髋请求绝对值中位0.170/0.338rad；当时髋探索标准差0.063、轮速探索约2.1–2.3rad/s。原噪声到160更新才收紧，停车所需精细动作探索出现过晚。此离线计算是诊断，不是独立物理成功率；动作请求处于容差内也不等于真实机器人已停稳。

停车成本使用25rad/s、0.75m/s及1.2rad缩放，在原0.02m/s、0.05rad合格边界附近敏感度不足，是本轮待检验的学习设计假设。已有实际物理探针能在四个初速组停住并持续保持，说明停车物理可达，不能把失败归咎于机器人结构。

## 前轮次终局补充

Restart15两路最终各0/64持续停车通过。seed70有54/64曾停稳0.5s，但最长只0.90s，之后216次保持中断全部由实际速度超限触发；3s后仍请求轮速中位0.926rad/s。seed71未达到0.5s，实测速度中位0.0396m/s，髋误差中位0.144rad，16例出现辅助前轮离地。原独立计时审查一致，失败来自真实残余运动与姿态，不能归咎于汇总计数或用放宽门槛处理。详见`restart15_result.json`。这些终局证据支持继续检验下列停车精度和探索方案，尚不证明修正一定有效。

## 修改与预先固定的预算

1. 仅辅助配置启用精细成本。原轮/速度/髋/髋速度/线偏/航向/偏航率成本保留一半，另一半采用`abs(error)/(scale+abs(error))`，scale依次为0.02/0.03rad/s、0.02m/s、0.05rad、0.5rad/s、0.02m、5°、0.05rad/s。大误差仍有原线性部分，小误差有更强梯度；成本总率上界仍5.7/s，保守6/s的失败补偿证明不变。世界pitch次级成本、真实判据不变。
2. 辅助前轮首次真实离地立即记质量失败5，补足原`−50−6×剩余时间`，不当成功，不允许用便宜早失败逃避成本。完整登台的首次合法离地不受此开关影响；配置校验禁止辅助开关默默用于完整任务。
3. STOP覆盖分别报告仍有资格与已失格的物理时间，质量失败另计。
4. 已知STOP的辅助任务不加熵奖励；保持随机PPO采样，方差上限在20→80更新收紧至髋0.01、轮0.03（归一化，轮对应0.375rad/s），不是手工固定动作或事后强制停车。完整任务尚不采用这套探索安排。
5. 两独立种子70/71，各512环境×64步×200更新，每份6,553,600条transition，是前次辅助的4倍；仍少于第14轮每份16,384,000。先做128/512工程吞吐与显存实测再部署，不能宣称未测量的加速。

这些改动检验一个联合的停车学习方案；两种子用于检查复现，不能据此分离每个因素的因果贡献。200更新为硬预算，不继承Restart15，也不拿工程短训模型继续正式训练。

## 验收和后续

先通过容器CPU反例、真实物理停止/质量失败/失败成本探针、512环境4→8同次恢复及16例独立重载、128环境同配置吞吐对照。工程通过只证明实现有效。辅助能力门槛仍是每种子64例至少61成功、每个初速组至少15/16，原actor持续原物理停稳0.5s后再保持2s，不能重置、冻结或覆盖输出。

辅助未通过则继续诊断，不发完整登台批次；辅助通过后再固定完整从零训练的预算、STOP覆盖及相对第14轮前段不退化审查。无论辅助成功多少，均不算上台阶成功。
