## 复位契约

沿用源项目 [PoseLoader](../../../robot_controller_demo/test/pose_snapshot_demo/pose_io.py) 的姿态加载语义：

- 水平位置归到模型默认值，当前为 x=y=0；保留完整四元数（wxyz，包括偏航）和全部关节角。
- 保留原始高度，仅在必要时向上修正，使初始碰撞几何到地面的最小间隙为1 mm；原始 JSON 保持只读。
- 清零线速度、角速度、关节速度、外力及仿真时间；控制量和求解器旧状态也重置。`qvel_at_capture` 与录制时的 IMU 读数仅供追溯，不重放手动摆姿态时的运动。
- 加载后直接作为回合起点，不增加预先沉降、随机姿态扰动或自动归位动作。开始推进动力学后的自然运动属于该次尝试，控制由探索环境负责，不能自动接入 demo 的位置保持或固定恢复流程。
- 每条训练与评估记录保留固定姿态编号，分别汇总四个初态的结果。首版不通过混合成功率掩盖某一初态的失败。

MuJoCo 可直接使用 `PoseLoader(model, data)` 加载原始模型。若训练使用其他物理引擎，需按关节名映射，核对浮动基座参考系、四元数约定及各环境原点，并在目标引擎重新检查高度和接触；不能直接照搬 MuJoCo 的数组索引或修正高度。四个初态在目标训练引擎中的复现是启动训练前的工程检查项。
