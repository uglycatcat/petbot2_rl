# Step第6轮：稳定归髋与减速反馈

第5轮两独立种子各512×500更新完整成功均0/64，前轮抬升越沿落顶均64/64。seed70有10例完成归髋和0.15m直行，但停车阶段仍请求6.48–7.89rad/s或更高轮速，实测最低0.169–0.212m/s，停车信用始终为0，最终驶出台面超时；其余54例与seed71的63例都因后轮失支撑终止。seed71一例曾四轮登台但未归髋，最终横向越界。无成功轨迹可审查；前阶段局部进展不能作完整能力通过。

seed71训练抽样唯一阶段2在髋以2.85/2.75rad/s穿过零位时拿到1.926/2归髋分，下一帧重新偏离。seed70有效稳定归髋例说明归位并非物理不可达，停车缺少低速阈值之外的渐进反馈。失败/存活样本早期髋速度和目标变化幅度相近，不凭相关性裁定后轮失败只由髋抖动造成，也不放宽真实后轮支撑标准。

`settle_v6`只修改奖励：原2分归髋信用改为1分位置×低关节速度质量（速度尺度0.5rad/s），加1分连续0.2秒四轮支持、沿线、髋误差≤0.05rad且髋速度≤0.5rad/s的保持信用；原停止0.5秒的1分保留，再增加1分完成规定直行后随实际速度0.3→0m/s递增的减速信用。全部仍经分项历史最佳差分，重复动作/驻留不能重复获分，无效终局不获新信用。总进展预算16→17；成功/失败终局奖励保持，gamma1有限回合。保持计时只服务奖励，不改变完成判据。

源模型、物理、动作映射与限制、26维自身传感actor、一次性感知、后轮/前轮失败判据、直行记忆和停车标准保持。未加载历史权重；已有动作仅用于有限匹配物理诊断，不进入PPO。新增`landing_probe --mode brake`在每个原回合第一次完成直行后才给归零髋/轮目标，检验停车可达性。未到该阶段的回合完整保留原动作。工程检查须核对匹配前缀/真实失败、短训/同次恢复/独立重载和512环境规模。

正式预算仍为两个独立种子70/71、每路512环境×500更新，物理GPU0/1，重新随机初始化。后轮衔接、实测轮速超调与动态估计漂移仍是主要待验证风险；本轮不声称已解决，不启动sim2sim。
