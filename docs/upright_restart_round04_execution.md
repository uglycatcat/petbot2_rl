1. BALANCE观测中的阶段时间2秒后封顶；真实计时、Space落地、超时、完成/失败规则不变。起立、落地、交接时间观测不改，训练/轨迹分别记录实际时间与策略时间。

4. 完整循环与基本遥控分开报告。每次换令后等待0.5秒，至少累计0.5秒实测，以窗口均值检查方向及明显欠响应/失控；非零指令响应至少25%，上界为2倍目标或零指令容差的2倍，停车均值容差0.05m/s/0.15rad/s。每回合要求前/后/左/右/停车覆盖且完成流程，才计basic_control_pass；这不是瞬时精度、全范围能力或用户MuJoCo验收。运动课开发晋级记录采用该值，保留原success字段的流程完成语义。第3轮原生两路按此辅助检查均0/32，不能掩盖转向缺失。
