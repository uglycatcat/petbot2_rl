## 修改

保留第7轮的有界Beta方差课程、26维自身传感actor观测、左右共同动作、全部PD/目标变化率/物理、`settle_v6`进展奖励和完整成功标准。新奖励版本`touch_v8`仅增加以下两项非正代价：

- 每2ms依据实际前轮平台法向力、接触点及原禁止接触分类，识别合法顶面接触；不等全轮廓越沿。这是奖励专用记忆`front_touched`，不输入actor、不改变阶段或成功判据。
- 顶面过载代价为每轮`dt * max(Fz / (整机质量*g) - 1, 0)^2`，只在合法顶面接触积分。正常静载低于整机重力不收费，短促或重复冲击均计入，不把控制周期末帧当作接触峰值。
- 双前轮已经真实触台、四轮尚未全部支持时，增加`dt * 0.027 * mean(髋实测角速度²)`。加上原0.003项，该段总权重0.03；不缩小髋或轮速权限，不指定动作时序。静止无此运动代价，四轮登台后恢复原权重。

原落顶冲击代价仍保留，已有正奖励上界和失败/超时终止价格不变。新代价不会给等待或反复动作增加正收益；可能使探索过于保守，是否提高持续后轮支撑和完整成功仍须两路新训练验证。新记录包含两项子步累计代价、真实触台记忆及原落地代价，支持独立核算。
