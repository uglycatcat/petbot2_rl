# upright_rl_demo 起立任务

## 当前需求（2026-10-19用户明确）

与recovery_agile_01独立推进，项目名称不变。目标从静止起立扩展为正常行驶中随时接管、平滑起立、后轮支撑下继续遥控行驶。

接管初态限定四轮均接触地面的正常行驶，不包含摔倒恢复。覆盖前进、后退、转向、原地转向以及左右相同的任意允许车架角度；速度和角速度的覆盖范围须在平台实际可达范围内标定，不能把所有极限组合视为都可立即起立。用户不要求预先刹停；起立期间允许必要的速度调整，目标是切换平滑并继续移动。原“最终回到接管位置”被遥控指令对应的运动轨迹跟踪取代。

起立完成后支持前进、后退和左右转向。遥控接口与初始速度范围由实现方选择便于训练的方案。车架仍输出位置目标，两侧共用；轮子仍输出速度，转向要求左右后轮独立，因此拟采用共享车架位置、左后轮速度、右后轮速度三路动作。头耳维持初始位置目标。

### 已确认的过渡期遥控方案（2026-10-19）

用户已确认：策略全程接收前后线速度及偏航角速度命令；起立时在可达加速度、转弯强度与平衡余量内平滑执行，允许暂时跟踪误差，不要求瞬时准确执行任意突变指令。稳定后逐步恢复正常命令响应。指令限速/限加速度不能代替实际可行域验证，也不能用无限延迟掩盖跟踪失败。

该方案已获实施授权，效果仍待验证。应通过真实滚动形成一致的机身/关节/接触初态，在运动中随机切入；交接需继承实际关节目标、轮速及观测历史，避免默认零动作和历史清零造成目标突跳。训练覆盖起立前后命令变化，分别评估起立成功率、速度/转向跟踪、轨迹偏差、速度跌落、动作与加速度变化及进入稳定支撑时间。

## 已完成基线（2026-10-17）

第五版b236e12仅验证默认构型、零速度起步，再起立回位。128上限双种子750检查点均64/64额外2秒保持，终局56/64和64/64；推荐B43/model_1499。左右轮共用速度目标，尚不支持后轮支撑遥控转向。该基线不证明运动中接管、长时保持、扰动或sim2sim能力，见[第五版终局](upright_v5_training.md)。以下为历史行为依据。

## 行为依据与实测

`jump_demo` 是关键行为参照：先让前轮离地，再维持后轮支撑平衡。它不是模仿轨迹、不作为训练数据；不要求RL复制先前进再后退的动作表。2026-10-16已在服务器anna用户下配置uv/MuJoCo环境，运行原控制器12秒并检查曲线和渲染关键帧：约2.522秒进入平衡，末段前轮中心约0.19m；最大水平偏移0.405m、末态偏移0.228m。因此它证明抬升/平衡，但没有完成回位目标。

首版GPU0/1双种子各2048×1500已经结束，6次评估稳定成功均0/64，详见[首版结果](upright_first_results.md)。第二版基于实际复现设计两阶段奖励、回位硬判据、窗口稳定检测；详见[第二版设计](upright_v2_design.md)。第二版两种子各2048×3000及8次检查点评估已结束；完整成功、阶段2及离地事件均0/64，未学会任务。奖励上涨仅来自准备阶段，std降至约0.02。终局与后续优先级见[第二版训练记录](upright_v2_training.md)。旧固定运行版本保留。
