# 移动起立阶段分析与过渡要求（2026-10-22）

用户允许讨论并放宽起立过程的指令跟随要求；正常行驶中接管、无需先停下、后轮支撑后可遥控仍是目标。是否采用具体过渡约束尚需验证，不宣称任意指令物理可行。

## 已有分阶段证据

来源为重建第三批A44/B44原生和heldout四组完整只读诊断，各64环境，路径`runs/_upright_rebuild_batch3/diagnostics/*/diagnostic.json`与evaluation.json。这是已完成的第三批小范围结果，不是仍受中断恢复影响的第四批终局。

四组有效离地中位数均0.42秒，最大0.60–0.66秒。接管0–1秒平均前进速度误差约0.102m/s，1–3秒降至0.017–0.019m/s，3–10秒为0.012–0.013m/s；0–1秒平均路径误差约0.042–0.043m，1秒后约0.023–0.036m。起立存在明显短时运动偏离，但这些小范围轨迹随后大多能够跟随。

头耳与roll条件在这四组末段均未出现不合格。支撑失败含已确认的物理步短力缺口，不能全部解释为真正摔倒；heldout另有真实失稳。结论：小范围“抬起”基本可完成，后段持续支撑/朝向仍是主要评分瓶颈。不能据此断言宽范围起立可行，也不能将所有失败归为过渡跟随约束。

## 建议的过渡契约

接管时继承实际速度与朝向，不先停车；起立期间以姿态和支撑安全为优先，允许有限短时速度、转向和位置偏离。保留遥控输入，但经可行的加速度/转向限制后用于过渡，不硬性要求原始指令瞬时精确跟踪。以后轮支撑稳定事件退出过渡，同时设置时限，防止策略长期留在宽松阶段；具体时限应根据更大初态范围实测确定，不能把0.66秒直接设为所有场景上限。

平衡建立后平滑恢复正常遥控。目标轨迹是否要求追回起立期间的偏移需独立定义：建议允许有限过渡偏移，并以真实状态连续接入后续目标轨迹，同时独立统计偏移上限、恢复时间和整体路径误差，不能借重置目标抹除评估误差。

因果验证应保留同一初态/命令集，用严格原轨迹与有限过渡容差对照，统一报告起立、支撑、遥控和平滑指标。先修已确认的终止/动作约束/低速判据，再做小范围平衡遥控与接管课程。域随机等不是当前阶段替代任务定义的手段。
