## 全模型范围仍待对齐和修改

当前修正尚未完成全范围设计；以下是待验证实现问题，不是尚待用户定义任务：

1. 源后轮目标±25rad/s、力矩0.38Nm，车架[-1,1.2]rad。理想纯直行0.75m/s、原地转向15rad/s属于同一对轮子的联合边界；混合指令必须落在两轮执行器可达域。取消旧额外小包络，不修改源电机参数。
2. 当前代码仍有0.4m/s²横向加速度过滤、2rad/s²转向命令变化率及3–4秒换令周期；只放大配置会导致满范围请求被过滤或未达到便换令。下一版根据状态实测判断保留或修改，不机械地全部移除；报告请求、执行命令与真实运动三者覆盖，不能让限制改变核心任务。
3. 普通行驶准备当前2–4秒触发、6秒等待截止，不能默认足够形成全范围实际速度。需要构造真实四轮行驶接管初态，覆盖实际速度、转向、可正常四轮支撑的车架构型；不清零动量、不把无效初态算成功。
4. 旧持续超速失败阈值、观测统计和冻结内部反馈都来自低速任务。重新审查是否误罚正常制动/摇摆、是否压制扩速；先验证再决定保留。旧基本功能评价不能替代新过渡偏航和实际速度覆盖。
5. 落地识别独立验证已落地/未落地/异常状态，比较候选方法的误判和交接延迟；不把取消超时或采用正解等同于最终修复。每轮落实[状态与关节轨迹审查](current_scope.md#每轮策略行为审查2026-10-27用户确认)，检查被标为成功的样本。完成对齐和修正后再做目标范围GPU工程验收，按批次训练和评估。三卡资源测试已经可用，不等于全范围设计/训练已通过。
