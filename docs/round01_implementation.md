## 观测、奖励和判断

单帧39维、五帧历史：重力方向、机体角速度、局部线/角速度估计、位置关节及速度、轮速、指令、过渡参考、已执行目标、阶段和相对航向等。没有全局位置或绝对航向输入，没有接触力输入。

切换用姿态/关节推算前轮相对后轮支撑面的间隙；支撑估计可能在腾空/滑移等条件下失准，须和实际轮高/接触轨迹核对。当前运动输入由仿真速度提供“估计接口”，没有声称已实现实机速度估计器。奖励/评分另读真实几何和接触，估计进入两轮不能单独领取真实成功。

起立奖励给有界最高进展增量，静止驻留没有持续正收益；两轮真实支撑和平稳跟踪才获持续奖励。落地给下降进展，完整交接另计成功。必要调整只有小成本，失败优先于成功。失败、感知不一致、实际轮速超调和力矩均单列。

进入两轮的候选几何间隙为75mm并保持0.30s；首次离地25mm确认0.06s、意外回落12mm确认0.12s；正常落地确认0.18s。起立超时12s、落地4s；这些工程数值待物理轨迹核对，不是已验证能力。
