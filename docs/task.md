# Step首版任务契约

2026-10-30用户确认；独立step项目已授权实现Isaac/PPO训练代码及必要工程验证，不包含sim2sim。以下任务目标与配置中的工程初值分别解释。

## 场景和动作

机器人以源模型默认姿态和零速度生成。以初始整机质量加权质心的地面投影为原点，初始前进方向为+x、左为+y、向上为+z。台阶前沿通过(0.30m, 0)，沿+y展开，顶面高0.02m。初始距离指平台前沿，不能改成机器人base原点距离、前轮距离或平台中心距离。台阶在复位时生成并固定，不随机器人移动，也不在接近时突然出现。

策略自主决定共同髋角和共同后轮速度。左右目标精确相同，不添加差速或独立左右修正器；姿态和路径误差仍基于真实运动测量，不人为锁定机器人横移、航向或翻滚。头部/脖子和耳朵保持默认零位，前轮保留源模型被动关节。

允许减速、短暂停顿，不主动倒车。动作接口将后轮目标限定在[0, min(25, 源上限)]rad/s；被动回滚与主动倒车分别记录。髋目标采用源关节范围，当前[-1,1.2]rad。策略输出是位置/速度目标，不是力矩；源MJCF髋、头、耳使用motor，后续适配器需要位置伺服并保留源力矩/摩擦等物理约束，不能把目标角直接写入力矩通道。

前轮在抵达台阶之前抬起，整个扫掠几何越过前沿后落到顶面，禁止前轮碰撞立面或棱边；只看轮中心高度不足以证明避碰。后轮允许接触立面、边沿和顶面并滚上，保持地形支撑，不训练跳跃。后轮轮心必然随登阶升高，“保持支撑”不等于锁定世界高度；瞬时接触力为零也不能未经几何/子步核查就解释为腾空。

## Lowerbody俯仰平顺性（2026-11-02用户确认，下批生效）

从第17轮之后的下一批开始，优化IMU所在`lower_body`相对于世界坐标系的pitch：登台过程尽量减小俯仰变化速度，同时避免过大的后仰和低头。允许髋关节主动发力抬前轮，也允许登台所需的适度姿态变化；不要求世界pitch恒为零。头/耳关节仍保持默认位置。此目标描述的是机体实际姿态与变化率，不能以髋/头关节相对角度或目标变化率替代。

工程上先用第17轮真实轨迹确定俯仰角、角速度及过大摆幅的基线，再设计平顺性和过大俯仰的软代价。用户未指定数值上限；不得直接把任意阈值当用户要求或新增硬失败条件。单次抬轮、避碰、后轮支撑、归髋沿线短行及真实停车保持，须检查新增代价是否诱发不动、不抬轮或提前停车。

从IMU姿态/陀螺数据得到世界参照pitch及其时间变化率，并与`lower_body`世界姿态独立核对安装轴、符号、单位和采样时间。一般姿态下，机体系陀螺Y分量或世界角速度Y分量都不能未经变换直接视为pitch变化率。分别记录传感估计/仿真真值、前后俯仰极值、变化率峰值及均方根、阶段轨迹和髋请求/执行/实测；仿真真值仍只用于奖励、诊断和验收。新版本必须经过容器工程门槛、提交推送、冻结后重新从零训练，仅GPU0/1。

第17轮`8a78033`固定副本保持；第18轮`pitch_v18`已实现2ms积分的`0.1·pitch_rate² + 2·max(|pitch|−0.35,0)²`软代价及真值/估计日志。0.35rad与权重为待验证工程初值，没有新增硬失败条件；其余输入、控制和完整验收保持。工程结果及正式启动见`docs/round18.md`和campaign状态。

## 完成与失败

**2026-11-02用户新增动作质量要求：** 一次上台阶过程中，前轮只允许一次真实离地，随后直接落到平台。台阶前试抬后回落再抬、落到平台后重复抬轮均不合格。应分别记录两前轮的离地/落地时刻与次数，以真实接触及几何、带时间确认的状态转换计数，避免把接触抖动或髋角峰值误计为离地。第16轮冻结实现未加入此约束；第17轮`clean_v17`已实现4mm/20ms离地及20ms接触确认、回地面/重复离地失败5和成功约束，先完成容器工程验证再从零训练。现有`relift_cost`只覆盖落顶后的重新抬升，不能代替完整离地次数约束。

顺序要求：双前轮均无碰撞地越过前沿并落到顶面；四轮全部上平台；髋角回默认0rad；在原来的行驶直线上继续直行一小段；最后停稳。原直线由初始位置和航向定义，不能登台后重设路线掩盖偏移。仅轮心越过前沿、仅前轮登台、车身位于顶面上方或四轮登台但未停稳均不算完成。

独立验收读取实际阶段、接触、轮几何、运动和关节轨迹。前轮立面/棱边碰撞、失去后轮支撑、机体碰撞/翻倒、主动倒车以及超时均不能成为成功样本。禁止用台阶碰撞后补抬轮、侧向绕行、跳跃、先滑上平台后伪造抬轮事件取得成功。

`CompletionTracker`只验证物理证据的组合和顺序，不制造动作或给actor阶段提示。未来后端必须证明每个输入标签正确，特别是双前轮“抬起→扫掠净空→顶面落轮”的时序、子步碰撞漏检及四轮真实顶面支撑。顶面落轮速度、冲击、车身晃动、目标变化率和后轮回滚保留为平顺性指标，不用一个未经验证的奖励总分替代。

## 一次性感知与观测边界

每回合开始时下发一次`TerrainPacket(height_m, distance_m, edge_angle_rad)`；首版固定0.02m、0.30m、π/2。边沿角是其切线相对初始前进方向的角度，不是台阶法线角。锁存的信息可以留在策略输入/记忆中，不能在运动期间重新测量或刷新为真值。

依靠IMU与关节编码器估计相对运动；`estimator.py`已实现陀螺积分、加速度重力补偿、关节正运动学质心偏置与后轮里程计融合。IMU重力补偿、旋转坐标变换、安装位置到质心的偏置、漂移和静止初始化需要在物理实现中验证。源仿真真位姿/真速度不能直接包装成`MotionEstimate`；轮速编码器可以提供自身关节信息，但轮缘速度不能当作无滑移的真实平移速度。

actor的26维候选原始输入为：锁存高度/距离/边沿sin与cos（4）、估计边沿法向距离和相对角sin与cos（3）、估计横向位置/航向sin与cos/前向与侧向速度（5）、自身重力方向和陀螺仪（6）、左右髋角/髋角速度/后轮角速度（6）、上一动作（2）。估计剩余距离由初始包和自身位移推算。actor/critic使用各自在线归一化的两层MLP，无历史教师或隐藏父策略，不引入接触标志、真实阶段、真剩余距离或未来地形信息。

仿真真值只进入奖励、诊断和独立验收通路；actor与验收之间无回流。若将来需要特权critic，须显式设计与记录，不能悄悄复用actor输入。
