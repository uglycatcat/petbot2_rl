# v28：修正从零起立奖励的接触占比抑制

依据[第25批终局](upright_cycle_batch25_results.md)与[后轮接触诊断](upright_scratch_rise_sequence_diagnostic.md)：两份1000更新没有进入两轮，物理动作序列可以抬高前轮；真实后轮仍贴地时，同刻双侧接触占比会很低，使起立奖励被压低。该发现是奖励指标适用性问题，未发现显存中断或传感器采样故障。

## 修改范围与边界

默认入口改为`configs/scratch_v3.json`，随机完整MLP、20ms策略、PPO参数、连续指令、镜像和课程保持。仅从零起立阶段：以实际后轮中心高度相对30mm轮半径衡量贴地程度，两轮均在1mm以内取1，任一轮超过10mm取0，中间线性衰减，超过3mm穿地也取0。这个有界量用于准备/抬升进展、抬升与过渡/平稳奖励，以及起立接触损失；四轮停留仍无持续正奖励，准备进展仍不可重复刷取。失败时起立正奖励为0。

后轮高度是训练奖励的物理量，在复位前状态快照采集，不增加actor观察或部署输入，不替代接触传感器与阶段判据。物理模型、执行器、±25rad/s轮目标、普通控制、独立调用、意外倒下退出、两轮/落地奖励与控制均保持。原0.30秒支撑比较及其浮点边界此次未调整，不能因诊断最大0.29999998秒而宣称进入两轮。实际轮速超调仍是独立未解决的质量问题。

C58只作桌面体验基准，不读入训练；双向连续0–0.75m/s、不同共同髋初态、起立少调整、落地只增默认髋位及每份正式1000更新要求保持。新课程状态版本5和奖励合同拒绝旧权重续入；历史试验只在各自固定副本重载，当前训练只允许同次中断恢复。
