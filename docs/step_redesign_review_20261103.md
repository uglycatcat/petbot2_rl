## 2. 已证实的问题与尚待验证的原因

1. 第14轮seed71有60/64完成规定短行，完整停稳0；第20轮相应36/64、0。实际STOP帧轮请求最小/中位分别18.39/22.53与11.65/11.93rad/s，真实速度最小/中位分别0.491/0.605与0.303/0.337m/s。策略持续驱动是实测事实。
2. 第14轮`phase`按当前支持、归髋和位置重新计算，可退回前段；`drive_start`可重置。当前条件标签、已经完成的任务步骤和策略应执行的目标混在了一起。接触龄波动不必然等于真实离地，不能靠无限放宽接触条件解决。
3. 第14轮实际生效奖励是`brake_v13`分支的有界进度/历史最好增量。不能把代码前面随后被覆盖的legacy前进奖励当作原因。停车没有形成稳定的动作目标；归因涉及目标门控、观测/价值状态、探索和末段采样覆盖，尚无“某一个因素解释全部失败”的证据。
4. 第20轮已有传感`stop_intent`和奖励侧`reward_stop_intent`锁存，第21轮已有持续轮请求/真实速度代价。第21轮在148/131更新由用户取消、未独立终局，不能声称其最终效果已被实验否定。下面方案不是把这些措施重新命名为新发现，而是重整阶段目标、归髋协调和验证次序。
5. 第20轮47次停车估计提示中11次未完成合法短行。必须区分“估计轮子越沿”“没有碰沿且真实四轮上台”“完成合法短行”，不能把一个估计位当作完整成功真值。
6. 同轮有限物理对照中，36条真正完成短行的轨迹，轮目标与髋目标同时归零有31条通过原完整判据；只归零轮目标则0条通过，髋仍偏离。另5条接触/距离失败保留。证明部分合法到达状态具备收尾的物理可达性，不是PPO学会，也不是可直接部署的传感触发方案。
7. MuJoCo默认失败后继续展示；第20轮0.56s碰沿后的动作已经处于训练原本终止之后。它们应记录为失败后表现，不能混入合法STOP统计。Isaac合法短行轨迹同样不停，故不能用预览模式解释掉停车缺陷。
8. 本次另读同一运行时的MuJoCo旧轨迹：第14轮0.4s已确认双前轮抬起，0.8s已越沿，1.04s双前轮已落顶但后轮失支撑；第20轮0.56s首次碰沿前双前轮均未确认抬起，world pitch约−60.5°、轮目标23.15rad/s。前段退步发生在停车之前，必须有独立的接近/净空闸门。证据为同审查目录的`mujoco_pre_failure_comparison.json`；没有为本次审查重新运行仿真。

## 3. 不改变的任务与实现边界

固定2cm/初始COM前30cm/90°，一次性地形包，左右共同髋角/共同后轮速度，头耳默认；前轮合法抬起越沿落台，后轮持续地形支撑，四轮上台后恢复默认髋、沿原直线完成0.15m，再实际停稳0.5s。默认髋容差0.05rad，原线横偏0.02m/航向5°，COM三维速率0.02m/s/世界yaw速率0.05rad/s及15s超时，沿用现有工程判据。

单次真实前轮离地与lower_body世界pitch平顺要求保留；第14轮不是这两项已达标的基线。源机器人、物理参数、目标范围与执行器不动。继续一个RSL-RL PPO actor控制两个物理动作，actor端仅用初始地形包和自身传感历史；不加入真值接触、真位姿或真阶段，不用脚本把动作强制归零后宣称策略学会。

历史权重、教师、演示/旧轨迹不进入新训练。旧轨迹仅用于离线审查、奖励算术和固定策略物理诊断。新学习实验必须各自随机初始化。

“冻结旧独立验收”指固定原功能判据及其短行计量，同时将已确认的单次离地要求作为独立质量判据贯穿全回合。按功能/质量两列报告，不能因为回退到第14轮就忽略新增要求。世界pitch幅度/速率属于全登台过程的质量目标，不能只在停车时检查。

## 4. 重设计：分开任务意图、当前状态与验收

### 4.1 单向任务意图，不替换独立验收器

奖励层新增明确的单向任务意图；它不直接覆盖动作，也不改变任务成功条件。

| 意图 | 进入依据，仅训练奖励侧使用真值 | 当前学习重点 |
|---|---|---|
| 接近/抬轮越沿 | 原始默认初态 | 沿原线接近、一次抬轮、完整扫掠避开边沿；不在远处反复试抬 |
| 后轮登台 | 双前轮已合法越沿落顶 | 前轮保持台面支撑，后轮滚上；不再领取前轮抬升奖励 |
| 归髋与短行 | 已真实四轮上台 | 恢复并保持默认髋，沿原线完成规定合法短行 |
| 停车与保持 | 原独立验收逻辑确认规定短行完成 | 撤销轮驱动，同时保持髋默认、路径和四轮支持，达到真实停稳 |

任务意图达到STOP后不因髋偏离或支持短缺重新变成“应该登台”。当前支持、髋、路径、真实离地与失败状态继续独立检查和记录；故意破坏姿态不能关闭停车代价。

**第一轮实现冻结旧独立验收和距离计量。** 不改变`drive_memory`的0.15m、合法条件和已有60ms短接触间隙处理，不把累计正向里程替代合法净位移，不把“曾经上台”替代当前四轮支持。意图锁存只影响学习反馈和日志。那5条固定诊断失败不能直接改判成功。

若以后要改变“已经完成的短行是否应在后续失去支持时被抹除”的语义，必须作为独立验收修订：逐项定义合法净位移、反向扣除及姿态/支持/原线中断处理，同时报告旧新判据，不能夹带在本次停车奖励改动中。首轮先看原判据下能否学会31条对照所证明可达的收尾行为。

### 4.2 Actor可用的进度信息与误差审计

保留第14轮26维自身传感主干。候选新增输入只来自现有IMU/编码器估计与一次性台阶包：前/后轮相对边沿的估计几何距离、估计归髋后净前进距离、停车意图/有效性记忆。连续量固定物理尺度，离散记忆保持0–1，避免稀有标志被经验归一化放大；实际维数和字段在接口实现前固定。

这些叫“估计进度”，不叫“合法任务已完成”。尤其后轮里程计有无滑滚动假设，上沿滑动会产生偏差。先对第14/20轮记录按首次落顶、后轮过沿、合法归髋、短行和STOP分别审计时间/距离误差，并单独重查47次提示中的11条反例，区分估计提前、接触/姿态不合法和之前已失败。

估计标志仅提供策略上下文，不把它接成强制停车开关。Actor仍同时看连续距离、速度、姿态和关节信息；部署时不接触仿真真值。训练奖励/验收使用真值，估计提示与真值不一致时如实记为估计问题。

Critic方案显式增加仅训练使用的任务意图、当前合法条件、未完成短行量、保持计时及奖励记忆，使价值估计能看到决定回报的状态；不把特权critic输入导出到actor。该变更需独立验证actor完全不受真值输入通路影响，而不是默默修改原26维接口。

第11轮已经试过critic扩展，两路规定直行由第10轮38/58退至0/0，不能把增加critic信息重新当作未经尝试的停车解法。本次候选只针对新定义的意图与记忆状态补足价值输入，必须单独对照；价值损失降低不作通过依据，也不与奖励改动一次性混入正式批次。

### 4.3 让停车同时约束驱动与髋，而非只等低速奖励

在STOP，关闭接近、抬轮和继续扩展短行的正收益。保留现有完成判据，停车反馈持续覆盖整个STOP阶段：

```text
STOP代价 = dt × (
    轮请求幅值代价
  + 真实COM速度/偏航速率代价
  + 髋请求偏离默认角的代价
  + 实测髋角偏差与髋角速度代价
  + 路径偏离与lower_body世界pitch运动代价)
```

请求和实测同时记录，避免把“指令零”当成已经静止，也避免只约束轮子而让髋继续抬头。归髋/短行段先约束髋保持，不能提前用STOP目标惩罚仍有必要的前进；抬轮/后轮登台阶段保持所需关节权限。world pitch与髋角是不同指标，不能互相替代。

上述STOP公式外，**单次真实离地监督贯穿完整回合，lower_body世界pitch变化率及过大幅度的软成本覆盖接近、抬轮、后轮登台、归髋和停车全部阶段**。它们不能随阶段切换被关闭，也不由“髋回0”代替。必要抬轮与全程姿态成本的权衡要先经真实轨迹回报核算和有限物理动作验证固定，不能再次用未核算的大惩罚压掉越沿动作。数值幅度界限与权重仍是待验证工程参数，不能冒称用户指定的硬限制。

初次候选保留第14轮动作映射与PPO分布，不同时重做执行器、探索课程和轮映射。Beta有限均值难输出严格边界零，但现有验收速度容差不是数学零，不能未经实验把动作分布定为唯一原因。只有独立停车诊断证明零附近表达/探索不足时，才单独比较一个全阶段一致的微小零速端区；不能按真阶段强制把轮目标变零。

**新增成本必须先过回报排序检查。** 不能简单叠加负成本：若提前二次抬轮终止的−5比继续承担停车代价更便宜，策略会学会提前失败。设计要明确成本上界、失败的剩余时域处理或相应终局代价，并在有限15s内比较合法完整停止、持续开走、提前停车、反复抬轮、提前失败和原地超时。未证明排序合理之前，不确定最终系数、不发完整训练。成功和失败终止仍按有限时域处理，不错误bootstrap。

## 5. 验证次序：先证明能学会收尾，再发全程实验

所有以下训练/仿真都属于后续执行方案，当前不启动。

1. **只读/CPU门槛。** 用已有真实记录检查任务意图门控、估计提示、动作请求/执行、奖励各分量和回报排序。正常短行前STOP代价必须为0，已经进入STOP后不能通过破坏支持/髋关闭；不同时间的提前失败不能套利。独立验收代码/阈值逐文件冻结。同步检查单次离地及世界pitch计算，不能用CPU代替后续物理验收。
2. **随机初始化的平台停车辅助诊断。** 独立任务从几何构造的台面支持状态开始，覆盖静止及0.2/0.4/0.6m/s前进、默认髋附近的姿态和关节扰动。使用源机器人及相同执行器、传感处理、两个动作、原速度/归髋/保持标准；确认初始物理有效，不能以穿透/注入持续外力制造成功。它的目标是测试PPO/动作接口能否学会减速并保持髋，不包含登台和0.15m信用，单独标记辅助成绩。
3. **辅助任务不得冒充全程或成为教师。** 两种子各自随机初始化，不读取历史轨迹/权重；辅助任务权重和状态不迁移到全程新实验，也不默认混入生产任务reset。辅助初态与地形包、IMU/编码器初始化必须一致；仿真真初速、真姿态和真阶段不得直接灌入actor或估计器。允许的估计器初值只能来自实际可知的复位约定及IMU/编码器校准，必须记录传感校准后的真实速度分组，不能以真值初始化消除观测误差。若诊断提供固定STOP目标，它只是这个辅助任务已知的指令，不能称作传感识别全流程阶段，也不能把这个常量指令带入完整任务冒充估计。

   辅助推进标准拟为两种子各64例中至少61例按原停止阈值保持0.5s，静止/0.2/0.4/0.6m/s四组各16例、每组至少15例；分组按校准后实际进入状态核验。另继续运行原actor2s诊断是否再次驱动/抬头：**物理持续步进、原actor持续输出，不reset、不冻结、不覆写轮/髋动作**。现有MuJoCo进入COMPLETE后会停止step，必须用专门的有限持续保持验证入口，不能以静止窗口证明2s保持。按速度组分别报告保持和再次动作；辅助成绩及2s诊断不混入原完整任务成功数。
4. **全程候选仍从随机初始化开始。** 从原默认初态、2cm/30cm/90°完整学习。将真实STOP进入回合数、STOP有效采样秒数、低轮请求探索覆盖、归髋保持、奖励/优势分布按每次更新记录。不能用总体回报上涨代替末段覆盖。起步有限工程试验必须先看到真实STOP数据再决定扩大预算；若末段几乎未覆盖，应停止并针对观测/探索/采样设计一个单独修正，不机械重复500更新，也不悄悄混入oracle辅助reset。
5. **能力与质量分别报告，最终都要满足。** 分别报告前轮碰沿、后轮支撑、四轮登台、归髋/合法短行、完整停稳；同时报告每轮真实离地次数及world pitch幅度/速率。第14轮固定策略仅作相同场景的参考评估，不作为新训练父网络。每个候选抽查成功和每类失败，分别统计失败前与失败后预览，不以末端静止或碰撞后上台冒充成功。
6. **跨引擎能力门槛。** ONNX数值一致、传感状态与动作映射移植通过后，先在MuJoCo严格失败模式审查边沿前的轮廓净空，再做继续预览。要检查2ms/20ms采样时序、IMU安装坐标与重力约定、髋PD/轮速度执行器、网格和接触；接口等价不等于轨迹跨引擎一致。不得为了“对齐”修改只读源机器人，也不在训练没改善前靠预览控制覆盖动作。最新候选预览与“效果升级”分别标记，保留用户查看最新结果的偏好，不再把版本选择归为用户的问题。

### 学习执行前的硬闸门

本设计不是立即发训的配置。**任何候选学习试验开始前**，必须另形成固定且已核查的执行规格，缺一项就不启动：

- 完整奖励方程、数值系数/尺度、有界函数与每回合代价上界；剩余时域/提前失败的精确处理及上述回报排序的通过证据。不能留成运行中凭经验随意调权重。
- 辅助/全程各自的环境数、更新数上限、评估场景和随机种子；辅助四速度组的物理/传感初始化检查及每组通过数。
- 全程每次检查的窗口，STOP覆盖所要求的独立合法回合数量、总有效秒数、跨更新分布与低轮请求探索数量；均须给具体数字。单条轨迹或大量复制同一回合的帧不能作为覆盖通过，未满足门槛不自动延长或重发同配置。
- 功能和质量逐项对照第14轮的相同物理场景，明确前轮碰沿、后轮失支撑、合法落顶/四轮上台不退化的定量条件。新模型尚未到达后段时不能拿停车代价变小当作进步；任何下降不得被总奖励或平均完成阶段抵消。
- 成功、失败后是否继续物理/actor的精确规则，正常任务验收、失败后预览和2s保持诊断必须分别标记。

这些数值需要实现前的有限物理与回报审计支持，本次没有编造已验证的取值。它们是**下一阶段执行阻塞项**，不是省略的自动默认值；当前用户暂停也是独立启动阻塞。若审计显示现有方案不可学习或前段退步，先修订设计，不启动新的完整训练赌结果。

本设计尚不声称能够保证下一次PPO收敛。最关键的改变是把收尾作为有明确可学习目标和独立闸门的任务来验证，并防止整体登台能力退化被局部奖励掩盖。辅助任务解决不了全程阶段识别与末段覆盖，这两项仍是全程实验独立门槛。

## 6. Subagent独立复查

本次仅一个审查agent `step_design_review`，只读核实发布历史、ONNX/训练来源、实际奖励分支、阶段/距离逻辑与真实轨迹，未启动训练或仿真、未修改实现。

独立结论为：**有条件认可下一阶段设计方向，不认可把当前稿当作可直接发训规格或能力通过。** 版本来源、验收冻结、PPO自行控制、辅助不迁移/不混算、从零训练及对第20/21轮的历史措辞通过。

审查要求的四项修订已写入正文：全程单次离地/world pitch监督；辅助初始化禁止真值泄漏；2s保持必须真实物理和原actor持续执行；训练前固定成本/失败处理、采样覆盖/预算及前段不退化的量化门槛。最后一项仍需实现前审计确定具体数值，不能据此宣称已经可以发训。

同一审查agent再次阅读修订稿，确认四项要求已准确落实；最终仍维持“有条件认可设计方向、具体数值执行规格与实测未完成、不允许发训”。没有增加第二个agent。

剩余风险包括里程计滑移、合法STOP样本不足、同一网络的阶段目标互相干扰，以及world pitch成本再次抑制必要抬升。设计把它们列为可观察的门槛，但只有后续实测能排除；本次审查不保证下一次PPO收敛。
