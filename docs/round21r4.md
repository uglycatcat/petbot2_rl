# 21r4：落地确认段的轮目标减速

21r3两份从零1000更新和8项评估有效。seed102低速32/32、高范围31/32，静止后退均值0.464cm；seed103课程停在±0.5，不当作满范围保留。102隔离MuJoCo10场景均完成，静止后退3.081→0.954cm，前进稳定速度略降且双向0.75未达。桌面第20轮保持。

开发干预发现投影起点0.04→0.075m后三场景执行与物理全帧相同，原轮目标变化率150rad/s²仍限制回零。较早加快回零使静止接触速度0.117→0.241m/s，不采用。只在LAND投影已完全生效、轮目标本来就在朝零减小时，允许最多450rad/s²回零；不越过零、不加快加速/反向加速，不改投影未完全生效时的目标、RISE/BALANCE、原髋控制或普通交接。实际电机力矩与源模型保持，不覆写速度或提前交接。

固定网络MuJoCo静止后退0.954→0.283cm、接触后总移动1.642→0.800cm；后退后松键略退（后退0.116→0.275cm，总移动0.972→1.297cm），持S继续后退约−0.146m/s。只是开发依据，不能认定策略提升或桌面通过；首次探针有广播形状错误，修正后重跑记录保留。

新增`landing_ground_brake_slew_rad_s2`，默认0保持旧配置；21r4取450，原0.04m投影起点不变。记录正常限速后额外回零量`landing_ground_brake_delta`。不新增奖励成本、历史网络或教师。通过133项容器检查后，还须2048短训、128环境4→8同次恢复/独立重载、固定21r3网络静止/低速/高范围PhysX核验，不能仅凭退出0发批。

工程通过才计划种子102/103各2048×1000、GPU2/3，从随机初始化独立学习；与21r3相同种子/预算对照，不续训其权重。保住运动表现和降低落地总运动同时成立才升级；原0.75目标、不同共同髋初态、左右镜像、完整控制权与异常退出契约保持。

“近地”严格指现有传感几何阈值，不是模拟器真实接触信号；可能比首次真实接触早数毫秒，不能声称所有触地前动作不变。记录两者分别核验。
