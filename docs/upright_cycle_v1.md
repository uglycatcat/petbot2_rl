# upright_rl_demo完整运动循环首版（2026-10-22）

## 已确认目标与范围

同一策略负责四轮运动接管→起立→后轮倒立摆遥控→平稳落地→普通四轮控制交接。过渡持续接收平滑指令、允许为平衡加减速，不以停车为前置步骤；稳定后不追回起立期间假想轨迹。落地车架衔接普通控制目标。正式基线见[current_scope.md](current_scope.md#移动起立完整任务契约2026-10-22用户确认)。

第四批旧任务已完整结束：原生A136/B113、独立种子94/84、宽范围8/8（各384），候选未晋升。新任务不复用旧成功口径。

## 实现与接口

新增train_cycle.py、upright/cycle.py、cycle_task.py、transfer.py；保留旧入口和全部固定副本。仍为对称车架位置+轮速共同/差分三个动作，头耳目标固定；新增模式、目标车架和阶段信息，49维×5帧。策略在起立/两轮运动/落地中始终掌握执行器，四轮稳定后ordinary驱动从当前目标经相同slew接续，非瞬时切换。

阶段：0四轮预热，1起立，2两轮遥控，3落地，4普通控制交接观察。起立3秒未完成、落地4秒未完成判失败；这些是首版工程预算，不代表所有初态物理可行。阶段1→2时仅一次将参考对齐实际位置/朝向，单独保留过渡偏移；不再用原路径追赶奖励。默认5–8秒接管时长后请求落地；外部可请求模式与车架目标。已开始落地后锁存四轮请求至交接，避免反复切换重置时限。

物理接触在每控制周期30个2ms物理步统计：后轮有效比例≥90%，同时无其它部位接触且前轮中心>0.12m才算支撑；body接触使用整个history，不恢复旧“整个支撑合取多数过滤”。此为明确的新定义，不同于旧末帧判据，需用回放和独立物理证据验证。进入稳定阶段要求支撑≥0.3秒。落地需四轮有效比例≥90%、姿态/角速度/前轮竖直速度及车架目标达标持续0.3秒，交接后再观察连续1秒。

当前候选动作限速：轮速480rad/s²（每60ms最多28.8rad/s），车架3/6rad/s对照；初测120/240未通过起立能力门槛，见下文。rate惩罚使用物理变化率归一化。失败优先于超时；低速跟踪阈值按0.005+0.25|v_cmd|与0.015+0.25|yaw_cmd|，仍有传感/数值噪声底限，不宣称无限小指令都必须产生可分辨位移。

评估分开报告流程完成complete与完整合格qualified：后者还要求两轮阶段至少20个评估样本，≥90%平衡达标、≥80%指令跟踪达标。另记录分阶段到达率、过渡偏移、跟踪误差、触地峰值力/速度和动作突变。complete仅说明完成落地交接，不等于qualified或实机安全。
