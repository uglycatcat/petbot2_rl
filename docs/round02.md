# 第2轮：有界探索与髋角目标权限

2026-10-31。第1轮固定`d313e9f`两种子各1000更新，重载各0/64完整、全部超时。两个策略均前进到约0.147m后以共同髋−1rad、轮目标0停车；训练没有双前轮有效抬升。两路高斯标准差膨胀到约1e6/1.1e5，评估原始动作100%被裁剪，物理/产物监督有效，任务能力失败。

## 修改与依据

- 使用RSL-RL 5.4.1原生`BetaDistribution`，随机动作和确定性均值直接位于[-1,1]。保留原生PPO的log-prob、KL和熵计算；Beta的熵在有界区间有上界，不能靠增大裁剪外噪声获得收益。`initial_std`字段只适用于保留的Gaussian兼容配置，Beta由原生参数头初始化。
- 学习率固定3e-4，停止第1轮升至0.01的自适应变化，先验证有界探索与学习的稳定性。actor/critic仍2×128 ELU、同一26维自身传感观测、两维对称动作；没有历史网络或权重。
- 髋角目标变化率3→100rad/s；这是软件位置目标的变化率，不是改变关节物理参数或要求实际关节达到该速度。髋位置范围[-1,1.2]rad、PD增益和源1.2Nm限矩保持。后轮目标[0,25]rad/s及目标变化率100rad/s²保持。
- 更新日志增加策略分布尺度，重载分析增加原始动作越界率；Beta越界或分布非有限直接拒绝。

奖励、场景、一次性感知、后轮支撑、前轮避碰和完整完成判据保持；不加入脚本控制器、教师或示范数据。

## 有限物理诊断

同32组直接/预调髋动作：原髋3rad/s、轮100rad/s²为0次达到双前轮提前抬升，最高双前轮最低点7.55mm；两者同时提高锁存9次，其中8次在失败前达到，最高59.90mm。分离因素后只提高髋为7次，只提高轮为0次，支持先只修改髋目标权限。额外12组延迟动作中髋组又有2次抬升；这9例均在失败前形成所需净空，首次抬升时后轮几何高度最高0.253mm、未触发失去支撑。仍没有完整越沿/落顶，不是任务通过。

逐帧控制核查：只提高髋组的髋输出估计峰值1.2Nm，目标仍在源范围内；实际后轮速度峰值25.17rad/s，目标不超过25rad/s，轻微物理超调单独保留，不能把目标限制当成实测速度限制。

所有诊断使用默认初始姿态及原2cm/30cm平台，源模型、力矩、物理参数和控制增益不变。固定证据：`step_lift_diagnostic_20261031`（`00f69e2`）和`step_lift_factors_20261031`（`4272e1e`），四个容器监督有效。只读分析诊断轨迹，不用于策略训练。
