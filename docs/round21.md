## 唯一训练变化

在第20轮配置上增加`post_drive_stop_cost="command_motion_v21"`。原奖励外新增每控制步代价：

```text
dt * active * [5 * (wheel_request / 25)^2
               + 2 * (max(COM_speed - 0.02, 0) / 0.3)^2]
```

`active`取上一个控制步的真实规定短行完成记忆`reward_stop_intent`。因此不会惩罚完成0.15m所需的最后一个驱动动作，只有满足真实四轮支持、合法单次前轮落台、默认髋、原直线以及短行距离之后才开始。记忆在后续接触间隙或髋姿态偏离时保持，每回合重置；不能通过离开归位/支持状态关闭代价。

请求项为策略当前共同后轮目标速度，运动项为真实整机质心速度；轮请求归零但仍运动时仍付运动代价。实际速度在既有0.02m/s容差内且请求零时新增代价为零，静止不产生持续正收益。5、2和0.3是工程学习权重/尺度，不是用户新增验收阈值，效果必须由从零正式结果验证。

这仅修改学习反馈：没有脚本制动、锁髋、阶段切换动作覆盖或额外actor真值。29维原始传感输入、0–1任务记忆尺度、一次性感知、对称动作、完整执行器权限、物理、单次离地/避碰/后轮支撑、0.15m短行和实际停稳0.5s均保持。lower_body世界俯仰软代价及0.1→1课程、末200更新/独立评估完整代价保持。两种子仍各512环境×500更新随机初始化，不加载历史训练权重。
