# upright MuJoCo 交互验证与正式项目准备

2026-10-27 用户确认：先用当前最佳已评估策略制作 WASD/Space 可体验的 MuJoCo 仿真，作为判断训练框架成熟度的依据。程序位于 `rl_project/std_s2s_upright_project`；`std_train_upright_project` 保持空。两者由 repo 和独立 `rlproj/` 分支管理。尚未迁移训练，也不移动或删除 runs；history 加入忽略规则，后续按依赖清单归档。

## 实施与验收

- W/S 前进后退，A/D 左右转，Space 请求起立或前轮落地；释放方向键请求零速。普通控制、起立中、两轮状态均接收遥控，过渡遵循现有平衡优先限幅。
- 使用已完成独立评估的真实策略，保留 58×5 观测、60 ms 外环、20 ms 冻结平衡反馈、2 ms 转向反馈、五阶段状态机、车架位置/后轮速度目标以及物理限幅。头耳维持初始目标。网络导出不等于 sim2sim 通过。
- 源 MJCF/STL/质量/接触参数只读。MuJoCo 电机接口用外部 PD 实现车架位置目标；迁移差异实测报告，不用脚本动作伪装策略成果。
- 部署新增手动起立请求和完整交接后重新接管，物理状态不重置；只有 R 显式复位。原训练随机换令/自动落地由外部操作者输入替代。
- 先对齐观测和控制，再测真实 MuJoCo 闭环、按键与渲染，记录失败、范围和默认权重的来源。没有跨引擎证据前，不判断“只剩调参”。
