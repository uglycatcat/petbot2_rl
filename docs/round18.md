`pitch_v18`只增加两项非负软代价，在每个2ms物理子步积分：

```
rate_cost  = dt * 0.1 * pitch_rate**2
angle_cost = dt * 2.0 * max(abs(pitch) - 0.35, 0)**2
```

对象是IMU所在`lower_body`相对世界的ZYX pitch，允许髋发力和必要姿态变化。0.35rad约20°是软代价起点，权重和起点为工程初值，不是用户指定阈值，不触发新的失败，不限定髋关节动作。角速度代价覆盖前轮抬升、落顶、后轮爬升及后续阶段；静止没有新增正奖励。禁止将“摆动小但不完成”视为成功。

xyzw四元数给出世界pitch与yaw；pitch变化率使用世界角速度经yaw变换。记录IMU姿态估计和机体系gyro经roll变换后的对应量，与真值并列用于审查。物理子步代价累计后在20ms策略周期扣除，避免漏记快速接触摆动。新增六个日志字段，29维actor/critic输入保持；真值、接触、阶段和新增代价均不进入actor。

第17轮的全部单次离地及原任务验收保持，轮请求仍为`25*clamp((a+0.9)/1.9,0,1)`，髋/轮目标斜率20rad/s和100rad/s²，默认头耳、对称命令、源模型和执行器参数保持。既有短行后主动减速/停稳奖励保留，不以脚本停车代替策略；传感停车提示仍可能提前或缺失。
