# Step第12轮：降低共同髋目标变化率

第11轮两独立种子均0/64完整。seed70全部前轮触边、0越沿/落顶；seed71全部前轮落顶、63例曾四轮支持，但64例后轮真实离地，均未归髋或达到规定直行。两路训练与评估工程有效；seed71的64个2ms首次离地窗口由独立轮廓/台阶几何复核，间隙4.014–10.410mm、力0，1578个样本误差≤1.51e-7m。新增critic状态使值函数损失降低，未带来行为收益，不以此指标决定保留方案。

seed70后段反复调髋，执行目标与实测髋角最大差0.757rad、实际髋速度14.10rad/s。seed71落顶后持续调髋/加减速，实际髋速度最高14.61rad/s、落顶后再抬前轮最高36.67mm。原动作回放逐项一致，真实轮速超调仍存在；这些不是工程无效或误判造成的策略分数。

有限4秒对照保留seed71原动作前缀，通过最后一例前轮落顶后，将髋目标变化率20→6rad/s，轮请求不变；原回合终止后的未定义动作只保持各自最后请求，不串用重置回合动作。前缀误差0，64例均维持至4秒、无失败、均曾四轮登台，4例进入规定直行；完整成功0。原64例全为后轮离地。该开放环诊断只支持降低快速摆髋的工程假设，不是新策略成绩，且没有证明从初始时刻就用6rad/s的学习效果。

因此撤回第11轮critic扩展，使用原actor/critic各26维自身传感/一次性感知接口。**相对第10轮，只将共同髋目标变化率从20降至6rad/s。** 对整个回合统一限速，每2ms目标最多变化0.012rad，不依据真实阶段、接触或台阶信息切换。保持髋目标完整区间[-1,1.2]rad、共同轮目标[0,25]rad/s及其100rad/s²变化率；左右目标同步、脖子与耳朵保持默认。6rad/s约为本轮观察到最大实测髋速度的四成，是待学习验证的平顺控制候选；不能把目标变化率当作实测关节速度上限。

源机器人、PD/力矩/关节物理、奖励、失败/成功判据、方差课程、PPO结构与512×500预算保持。保留旧critic选项代码用于历史重载，新配置不启用；两个网络与优化器重新随机初始化，不加载工程/历史权重、教师或诊断数据。正式仅GPU0/1，不含sim2sim。

工程须验证实际目标增量、请求/执行/实测区别、PPO短训/完整恢复/独立重载、512规模及固定动作在新限速下的真实接触与终局。因控制明确改变，新旧物理轨迹不应被要求完全相同；独立奖励/验收重算和源模型指纹仍必须通过。正式效果待新种子训练结果，不据有限4秒维持宣称完整任务通过。
