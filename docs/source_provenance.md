# 新第1轮源码来源

历史来源是代码参考，不是模型初始化或策略能力证据。当前运行不依赖归档目录存在。

| 模块 | 来源与处理 |
|---|---|
| `upright/model.py` | 静止v5 `b236e12`的只读MJCF解析、资产指纹；改为确定相对模型路径，补几何读取和新实现指纹 |
| `upright/prepare.py` | 同版本的派生MJCF/USD转换、关节命名、源质量核对与接触材料适配；新增执行暂停检查 |
| `upright/asset_cfg.py` | 同版本的源限幅位置/速度伺服、被动前轮配置；保留原实现 |
| `upright/distribution.py` | 同版本有界Beta分布，使用shape cap128；应用到髋/共同轮速/差速三通道，无旧权重 |
| `upright/controller.py`、`runtime.py`、`task.py` | 新的组合实现；参照早期完整循环`c3bb859`的流程经验，修正指令混淆与髋回位阻塞交接，不继承旧任务类 |
| `upright/geometry.py` | 从源关节/轮轴位置计算相对支撑几何；局部运动输入沿用历史长时稳定性经验，未引用父网络 |
| `upright/learning.py`及入口 | 复用原生RSL-RL5 PPO/MLP调用方式，新增严格运行身份与完整状态保存；没有transfer/warm-start接口 |

没有恢复旧静止“回原点”目标、冻结父actor、外层残差策略、多代任务继承或旧移动第五轮以后的废弃优化数据。旧效果只说明相应历史策略的能力，不能证明本版从零学习成功。

转换器的PhysX接触适配仍有跨引擎近似：源场景非轮子/地面摩擦0.1、前轮0.1、后轮1.4以minimum combine映射，自接触及扭转摩擦并非逐项等价。位置伺服增益沿用既有工程控制器，不是实机辨识值。源MJCF/STL、质量/惯量、关节范围及力矩均不修改；实际转换及轨迹待容器工程验收。
