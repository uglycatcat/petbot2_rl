# 21r3：近地LAND轮目标区间，从零学习适应

21r2在600更新以前两组actor/critic逐项相同，启用成本后quality高范围0/32、control29/32；静止后退quality3.929cm比无成本2.317cm更差。停止该惩罚课程，保留其失败记录。

候选基于control配置，所有新增LAND运动成本为0。仅LAND共同轮目标增加传感几何投影：估计前轮相对后轮支撑面的间隙≥0.04m时原动作完全保持；降至原地面判据0.012m时，逐步收敛到入口实际纵向速度对应的`[min(0,v_entry/0.03), max(0,v_entry/0.03)]`轮目标区间。允许同方向减速，抑制主动反向加速。差速航向反馈、原轮速变化率、髋自由度、落地确认时序和普通控制接管均保持；物理速度不覆写、真值不进入控制。请求动作、投影前后与实际状态分别记录。

这属于控制动作接口修改，固定网络的收益不能称为PPO提升。新实验仍须从随机初始化独立学习完整循环；单Actor–Critic、课程和运动奖励保持。阶段参数仍共享，不能保证新学习的运动能力不退步。两份各2048×1000、种子102/103、GPU2/3，只有工程和固定网络保留检查通过才发批，不继承control模型。
