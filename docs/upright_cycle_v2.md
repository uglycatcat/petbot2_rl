# 完整循环第二版：落地进展与遥控跟踪（2026-10-22）

依据[第一批终局](upright_cycle_batch1_results.md)，不扩大速度范围、不放宽完整合格标准、不改源模型。

## 修改

- 落地奖励由重复获得的姿态分数改为相邻控制步进展：降低前轮、回正姿态、接近请求车架。静止不反复得分；阶段时间成本2/秒，温和运动/接触等持续小奖励合计仍不足抵消等待成本。
- 触地前按前轮离地高度限制下降速度：0.08+sqrt(2×0.6×高度)，上限0.6m/s；超过包络即惩罚，不等待碰撞后才扣分。这是仿真候选反馈，非实机安全认证。
- 两轮遥控奖励宽度为现有速度/角速度容差的两倍；完整合格判据不变。A/B只比较遥控奖励权重6/12，统一车架3rad/s、轮速480rad/s²。
- 显式从完整循环第一批同种子A终局迁移actor，保持49×5观测和动作接口，critic/优化器重新初始化。仍用小范围±0.05m/s、±0.15rad/s、车架±0.15rad；新旧成功判据相同，训练契约指纹独立。

CUDA检查通过：阶段、参考对齐、重置、失败优先、actor映射、静止无重复落地进展、触地前快速下降惩罚及低速下降免罚。GPU短训与资源验收进行中；未经重载验收不会正式启动。

正式计划：6对种子、12组2048×600，学习率0.0001；100/300/599原生与终局独立种子/宽范围共60评估。实时资源不足排队，启动期间持续检查已启动组，发现中断停止补位。固定版本、实际进程及验收以对应launch_status和gate为准。
