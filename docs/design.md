# 独立台阶任务实现

## 任务与成功

平地默认构型生成，多样性与质量基线平台高0.07m，高度路线按本次配置提高（原5cm交付为0.05m），顶面2m×2m，前沿当前设为初始基座前0.65m（约为最前端前0.5m）。左右关节独立，不指定爬升动作顺序；身体接触、后退、转向、抬轮和大姿态变化本身不终止回合。四轮到台面即成功，没有停车、归姿态或保持时间。

实现用轮子源网格最低点、轮心处于平台范围、竖直接触力联合识别台面支撑。首版几何容差4mm、最低支持力0.03N、轮心越沿余量3mm；这些是接触数值容差，不是额外动作要求。空中越过边沿、撞立面和在台下不能算成功。独立评估另起进程加载本批检查点，从默认平地状态执行，再从存储的物理轨迹重新计算判据。

回合10s（工程选择），仅成功、超时或离开场景边界结束；时间到不bootstrap。初态不借用已登台姿态，训练始终使用当前配置的完整高度任务。

## 控制与物理

源MJCF/STL只读，由MuJoCo编译后将质量、惯量、质心、关节坐标与限位、网格凸包写成独立USD。训练在PhysX中进行，不使用其他任务派生资产。双耳按用户锁住要求在默认位置施加固定约束，保留其质量、惯量和碰撞。

策略5维原始Gaussian动作保留在PPO storage中，环境内tanh映射至角度或速度目标：头±1.3rad，车架−1至+1.2rad，后轮±25rad/s。每2ms执行角度伺服，后轮由PhysX隐式速度驱动跟随；头/车架/后轮的驱动力矩分别限制为0.72/1.2/0.38N·m。后轮速度增益0.14来自源模型；角度增益为本项目工程选择。源被动阻尼和frictionloss独立施加，摩擦的零速过渡使用tanh(v/0.01)。轮子保持仅与地形碰撞；身体自碰保留。

源scene中身体/地面显式摩擦0.1与身体自碰摩擦0.6通过互斥的两组碰撞形状映射，避免同一对形状重复接触。前轮优先摩擦0.1、后轮与地形组合摩擦1.5。PhysX和MuJoCo接触求解器不同，不能把资产映射表述为两个引擎轨迹完全等价；重点核对质量、几何、关节接口和实际支撑。

## 观测与学习

允许直接读取台阶相对位置/距离。首版为40维观测：本体线/角速度、投影重力、3个角度关节位置、7个活动关节速度、身体坐标中的台沿相对位置和朝向、台高、4轮距台沿/顶面的差值、上次动作和回合时间。前后轮绝对转角不参与观测。

独立MLP PPO，RSL-RL 3.1.2，actor/critic各256–128–64、ELU、观测归一化；gamma0.995、GAE0.95。动作噪声和奖励系数是可迭代的探索参数，不是用户需求。

奖励为本回合最佳登台距离/临沿高度进展增量、每轮首次真实落顶、四轮成功和小时间成本；不奖励原地反复抬轮，不限制左右对称、姿态平顺或接触顺序。每批从零训练；权重只用于同批受迫中断恢复、独立评估或最终交付。

## 验证与迭代

必要工程门槛：真实PhysX默认站立/质量、平台上四轮正例、空中与平地负例、独立角度/轮速响应；短训、同次恢复及独立加载。正例仅测试判据，不作为训练初态或示范轨迹。

正式批次固定提交，GPU0/1各一路。先读TensorBoard学习/覆盖，再抽查成功和失败原始轨迹；如有成功，必须检查是否为边沿/空中误判。继续自动迭代直至能够交付实际完成任务的策略。源码改动先验证相关路径，再提交发布和冻结，不热改在跑副本。

上游仅使用通用仿真与PPO接口：[Isaac Lab 2.3.2](https://github.com/isaac-sim/IsaacLab/tree/v2.3.2)、[RSL-RL 3.1.2](https://github.com/leggedrobotics/rsl_rl/tree/v3.1.2)。没有读取或迁移其他STEP任务实现。
